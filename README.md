# Fitcore Pro Dashboard

Build a modern professional web frontend for my project:

FITCORE – Smart Gym Membership Management System.

This is a gym management system originally developed using Java Swing and MySQL. I now need a modern responsive web frontend with a premium gym-management dashboard design.

Create these pages:

1. Login

2. Dashboard

3. Member Management

4. Payment Management

5. Trainer Management

6. Attendance Management

7. Membership Plans

8. Member Search

9. Payment History

10. Pending Fees

Design requirements:

- Premium modern gym-style UI

- Dark black/charcoal background

- Professional red accent color

- Clean cards and rounded corners

- Modern sidebar navigation

- Responsive design for desktop, tablet and mobile

- Dashboard with statistics cards

- Use realistic gym-related icons

- Professional typography

- Smooth hover effects and transitions

- Clean tables for members, payments and trainers

- Forms should look professional

- Do not add unnecessary AI features

- Keep the project name as FITCORE

- Add a professional FITCORE logo/text in the sidebar

- Make the UI suitable for a college project presentation and portfolio

Dashboard should show:

- Total Members

- Active Members

- Total Trainers

- Today's Attendance

- Pending Payments

- Expiring Memberships

Use realistic sample data for the frontend.

Do not connect to a database yet.

Create the complete frontend UI first.
